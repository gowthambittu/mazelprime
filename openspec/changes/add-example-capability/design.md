# Design

## Context
The repository is a static site with no local backend. The example must demonstrate valid delta structure without adding production functionality or contacting Netlify.

## Decisions
Use a hypothetical local-only preview label as an added requirement. Keep the example clearly separate from the real discovery form and leave implementation tasks unchecked.

## Alternatives Considered
- A live form-submission example was rejected because it could transmit customer-like data or imply deployment approval.
- A production health endpoint was rejected because the repository has no application server.
