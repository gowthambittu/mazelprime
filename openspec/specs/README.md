# Canonical specifications

Canonical specifications live here, one folder per capability (`specs/<capability>/spec.md`). Deltas from archived changes merge back into these files.

Each canonical spec has a Purpose longer than 50 characters, a Requirements section, SHALL/MUST requirement statements, and GIVEN/WHEN/THEN scenarios under `#### Scenario:` headings.

`example/spec.md` is a copy-me reference only, not a real MazelPrime capability. Replace or delete it when adding the first real specification through a change.
